Right now, my main project is **Watchman**, a lightweight Windows network monitor that helps users understand what their PC is doing with the internet in real time.

- Local-first tools
- Clean product websites

## Featured Project

### Watchman

Watchman is a local-first Windows network monitor that shows:

- Live download and upload speed
- Per-app bandwidth activity
- Traffic history
- CPU, RAM, and GPU usage
- Connection health
- M-Lab speed tests
- CSV export
- A compact taskbar widget

Website: [watchman.blinkeye.app](https://watchman.blinkeye.app/)  
GitHub: [Watchman Repository](https://github.com/rayhan138/Watchman)
